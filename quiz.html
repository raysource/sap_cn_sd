概念

1. SD 模块的核心产出是什么？

销售凭证（询价/报价/订单/交货/发票）
物料凭证与库存
会计凭证
生产订单
答案 A。SD 负责销售凭证；物料凭证由 MM 在发货过账时产生，会计凭证由 FI 在发票过账时产生。
概念

2. 哪一步才真正减少库存？

保存销售订单
创建外向交货
交货的发货过账（PGI，移动类型 601）
发票过账
答案 C。订单只是承诺；交货只做准备；发货过账（移动类型 601）才生成物料凭证并减少库存。
概念

3. 「销售范围」由哪三个键组成？

销售组织 + 公司代码 + 工厂
销售组织 + 分销渠道 + 产品组
公司代码 + 分销渠道 + 销售办公室
销售组织 + 销售办公室 + 销售组
答案 B。销售范围 Sales Area = 销售组织 + 分销渠道 + 产品组；它是客户/物料销售视图与条件记录的组织键。
概念

4. 发票过账（下达）时生成的会计凭证通常是？

借 收入 / 贷 客户应收
借 客户应收 / 贷 收入 + 销项税
借 库存 / 贷 应付
不生成会计凭证
答案 B。发票下达生成 FI 凭证：借客户应收（含税），贷销售收入（净价值）与销项税。
概念

5. 下面哪个说法是错的？

价格维护在条件记录里
一个公司代码可以有多个销售组织
交货单创建时就减少库存
一个客户可以有多个伙伴角色
答案 C。交货单创建时库存不变；只有发货过账才减少库存。其余说法都正确。
组织

6. 把销售组织分配给公司代码，含义是？

决定销售组织属于哪个会计主体
决定销售组织下有哪些分销渠道
决定发货工厂
决定客户编号范围
答案 A。销售组织与公司代码是多对一：决定这笔销售业务的收入落在哪个公司代码的账上。
组织

7. 起运点（Shipping Point）的作用是？

决定价格
决定发货的起始地点，与工厂多对多
决定收入科目
决定开票类型
答案 B。起运点决定发货地点（教材例：Z999 颐宁装运点），与工厂是多对多关系。
组织

8. 拣配库存地点的确定条件，教材里启用了哪几个？

起运点 + 工厂（+ 存储条件）
客户 + 物料
销售组织 + 产品组
公司代码 + 工厂
答案 A。后台「分配拣配地点」由起运点、工厂和存储条件决定；教材场景只启用前两个。
组织

9. 销售办公室（Sales Office）的主要用途是？

计算价格
统计与权限等机构/地区维度的管理
决定税码
决定工厂
答案 B。销售办公室与销售组是组织机构，用于统计与权限；不参与定价逻辑。
主数据

10. 客户主数据分三层，销售范围层放的是？

名称地址等一般信息
对账科目与付款条件
客户定价过程、运送条件、税分类、伙伴角色等销售数据
物料清单
答案 C。一般数据全公司共用，公司代码层放财务数据，销售范围层放销售相关数据。
主数据

11. 四个伙伴角色中，决定「货送到哪里」的是？

售达方
送达方（收货方）
收票方
付款方
答案 B。送达方（Ship-to）决定交货的收货地与收货人。
主数据

12. 销售价格（PR00）维护在？

物料主数据的销售视图
客户主数据
条件记录（VK11）
销售订单里手动输入
答案 C。价格在条件记录里（条件类型 PR00，VK11 创建）；物料销售视图只决定能不能卖、税分类、账户分配组等。
主数据

13. 想让两个物料走两个不同的销售收入科目，教材的做法是？

改定价过程的计算类型
给物料设置不同的账户分配组（M1/M2）
改客户编号
改销售范围
答案 B。账户确定用「账码 + 物料账户分配组 + 客户账户分配组」；教材通过 M1 自制产品 / M2 贸易商品区分收入科目。
主数据

14. 客户账户组的屏幕格式配置决定什么？

客户编号的范围
客户主数据里哪些字段必填/可选/隐藏
客户的信用额度
客户的付款条件
答案 B。账户组的字段状态决定客户主数据屏幕的显示与必填规则。
定价

15. 条件技术从「价格从哪查」到「用哪套过程」，正确的顺序是？

条件类型 → 条件表 → 定价过程 → 存取顺序
条件表 → 存取顺序 → 条件类型 → 定价过程 → 定价过程确定
定价过程 → 条件表 → 存取顺序 → 条件类型
存取顺序 → 定价过程 → 条件表 → 条件类型
答案 B。条件表存值 → 存取顺序定优先级 → 条件类型分类 → 定价过程排步骤 → 定价过程确定选过程。
定价

16. 定价过程确定（决定用哪套定价过程）的三个键是？

销售组织 + 工厂 + 客户
销售范围 + 客户定价过程 + 单据定价过程
公司代码 + 物料 + 客户
分销渠道 + 产品组 + 客户组
答案 B。IMG「定义并分配定价过程」里用销售范围、客户定价过程、单据定价过程三个键确定。
定价

17. 定价过程里的「账码（Account Key）」例如 ERL 的作用是？

决定折扣的百分比
决定这条条件金额记到哪个会计科目（配合账户分配组）
决定税码
决定交货日期
答案 B。账码参与账户确定：账码 + 物料/客户账户分配组 → 收入等科目。
定价

18. 条件类型 PR00 的「存取顺序」的作用是？

决定价格的显示格式
决定按什么优先级去找条件记录（先找谁的价）
决定货币
决定税
答案 B。存取顺序按优先级列出若干条件表，系统从头找、找到即停。
定价

19. 销项税税额由什么决定？

物料主数据的价格
客户税分类 + 物料税分类 → 税码，再按税率计算
销售组织
付款条件
答案 B。税码由客户税分类与物料税分类（+ 国家相关规则）确定，MWST 条件记录提供税率。
定价

20. 改了条件记录，之前保存的订单为什么没变？

系统缓存问题
单据是快照，主数据变更只影响新单据（或需手动重新定价）
条件记录没保存
用户权限问题
答案 B。单据保存时数据即固化，保证历史单据可追溯；要变更需在单据里重新定价。
流程

21. 想要给客户正式报价，用什么 T-code？

VA11
VA21
VA01
VF01
答案 B。VA21 创建报价（QT）；VA11 是询价，VA01 是销售订单，VF01 是发票。
流程

22. 参照报价创建销售订单，教材用的入口是？

VA01 里手动输入报价号
报价的「后继功能 → V-01 订单」
VL01N
VF01
答案 B。教材任务 41 从报价的后继功能进入并点「有参照创建」。VA01 手动参照也可以。
流程

23. 教材里创建外向交货的 T-code 是？

VL01N
VL02N
VL03N
VL06O
答案 A。VL01N 创建单个交货；VL02N 更改（拣配/发货过账）；VL03N 显示；VL06O 交货清单。
流程

24. 订单保存时系统提示「无可用库存」，正确理解是？

订单保存失败
默认可以继续保存，只是给出确认日期；后续发货前需补库存
必须立刻删单
系统自动采购
答案 B。可用性检查默认不阻止保存；教材用 MB1C + 501 录入期初库存解决后续发货问题。
流程

25. 补期初库存教材用哪个移动类型？

101
261
501
601
答案 C。501 是「无采购订单收货」，教材用它录入期初库存；101 一般用于对采购订单/生产订单收货，601 是发货出库。
流程

26. 发票保存后还需要做什么才能到财务会计？

什么都不用做
下达（Release to Accounting，VF02）
重新保存一次
在 FI 手工录凭证
答案 B。保存只生成 SD 发票凭证；下达后才生成会计凭证，系统提示「凭证已经传送到记账」。
流程

27. 要取消一次错误的发货过账，用什么？

VL09
VL01N 重建
VA02 改订单
VF11
答案 A。VL09 取消发货过账；VF11 是取消发票。顺序上通常先处理下游单据。

28. 客户问「我的货走到哪了」，最直接的工具是？

MCTA
单据流（VA03/VL03N → 环境 → 显示单据流）
FS00
MM01
答案 B。单据流一眼看到上下游单据与状态；也可看交货状态与发货状态字段。
分析

29. 销售分析（MCTA）报表没有数据，最可能的原因是？

报表程序坏了
更新组未激活或客户/物料统计组未维护
没有输入客户
系统语言设置
答案 B。分析报表依赖后勤信息系统的统计更新（任务 31/32）与主数据统计组；且只统计配置之后产生的数据。
分析

30. 教材中「无法创建 VL01N 外向交货单」的解决办法是？

改订单类型
用 MB1C + 移动类型 501 录入期初库存
重开系统
删除订单重建
答案 B。教材任务 48 第 23 步给出的办法：MB1C 501 无订单收货录入期初库存，使交货可行。
