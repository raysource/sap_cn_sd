1. 开票解决什么

问题开票怎么回答
开多少金额按交货数量 × 条件价格算出净价值，再加销项税
开给谁收票方 / 付款方（伙伴角色）
什么时候开交货完成（发货过账）之后；可用开票日期与发票清单（VF04）批量处理
财务上怎么记过账时生成会计凭证：借 客户应收 / 贷 收入 + 销项税（科目由账户确定推出）
发票与交货的关系以交货为基础开票（Delivery-related billing）是最常见的方式：发票参照交货创建，发票数量来自交货的已发货数量。也可以基于订单（订单相关开票）或做贷项凭证（退货/冲销）。教材场景是「交货 → 发票 → 下达」的标准链路。

2. 创建发票（VF01）

教材菜单路径（创建发票凭证）后勤 → 销售和分销 → 出具发票 → 出具发票凭证 → VF01-创建
发票画面关键字段含义教材场景值
单据类型决定发票类别（如 F2 发票、G2 贷项凭证）F2
发票号系统按编号范围生成90000000
付款方谁付钱（决定应收对象）10000000
出具发票日期记账日期相关的凭证日期2021.04.15
净价值条件计算的结果（不含税或含税取决于配置与条件）960,000.00 RMB
项目 / 物料 / 开票数量来自交货的已发货数量铸钢泵 170-230 / 120 PC / 物料 F999-100
开票画面上的「缺失数据」提示不是错误教材任务 43 的画面里，右侧「缺失数据」列出开票类型、出具发票日期等还没填的字段——这是系统在提示必填项，填好后保存即可。看到「缺失数据」不要慌，逐项补上。
这些数值是哪来的以上是教材环境发票画面上的实际可见数值（本站核对过画面）。在你的系统里数值必然不同——重点是字段之间的关系：开票数量来自交货，净价值来自条件，付款方来自客户主数据。

3. 过账（下达）到财务会计 VF02

保存发票只生成 SD 的发票凭证，还没有记账。要到财务会计，需要「下达」（Release to Accounting），教材里用 VF02 修改，然后按「小旗子」按钮，画面下方会提示 「凭证已经传送到记账」。

「下达」这个词要记住

保存 ≠ 记账。发票保存后状态是「未过账/待下达」，只有下达后才：

  1. 生成会计凭证（FI）；
  2. 应收挂到客户头上（可用 FBL5N 看到未清项）；
  3. 开票状态回写到订单与交货。

批量下达可用 VF04（开票清单）/ VF06 后台作业。

4. 会计凭证怎么来的（账户确定）

会计凭证行借贷金额来源科目怎么定的
客户应收借方发票总额（含税）付款方的对账科目（客户主数据 + 统驭科目配置）
销售收入贷方净价值账户确定：账码（定价过程的 ERL）+ 物料账户分配组 + 客户账户分配组 → VKOA
销项税贷方税额税码（由客户税分类 + 物料税分类确定）对应的税科目
想让「收入记到别的科目」怎么办三条路：改物料的账户分配组（比如自制产品 vs 贸易商品）、改客户的账户分配组、或改定价过程里的账码。教材场景用了第一条：M1 自制产品 / M2 贸易商品 → 两个收入科目。

5. 凭据链：点「原始凭证」能一路点回订单

教材任务 45「点击原始凭证」就是在验证这条链：发票 → 交货 → 订单。这是 SD 最实用的排查工具——客户问「这张发票对应哪张订单」，点几下就能回答。

6. 收款与清账（流程闭环）

收款属于 FI 的日常操作，不是 SD 的动作，但业务上必须知道流程在哪里结束：

动作T-code说明
查客户未清项FBL5N看这张发票是否还挂着未清
收款并清账F-28输入客户、金额、银行科目，勾选要清的发票
自动收款（银行对账单）FF67 等银行流水自动匹配（依配置）
催款F150到期未付自动生成催款函
教材范围提示教材的 SD 链路到「发票过账（VF02）→ 点原始凭证」为止，没有演示收款。上面的收款部分是本课程按标准流程补的，标注在这里以免与教材混淆。
