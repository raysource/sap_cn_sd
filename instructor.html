2. 板书路线（按这个顺序写白板）

  1. 先画一个大框「SD」，四周写邻居：FI / MM / PP / CO，各写一句话分工（← 用 集成结构图）。
  2. 在中间画三个矩形：销售组织 / 分销渠道 / 产品组，连线写出「销售范围」（← 组织结构图）。
  3. 下方画装运：工厂 → 起运点 → 装载点 → 拣配库存地点。
  4. 右侧写「主数据」三块：客户 / 物料 / 条件记录，各标一句「决定什么」。
  5. 中间写定价四层：条件表 → 存取顺序 → 条件类型 → 定价过程，再加一条「定价过程确定三键」。
  6. 最后拉一条横向时间轴：询价 → 报价 → 订单 → 交货 → 发货过账 → 发票 → 下达 → 收款（← 端到端流程图）。
  7. 每讲完一块，回到这张白板图指出「现在讲的是哪一部分」。不要一页一页念 PPT。

3. 必问问题与标准答案（采分点）

#问题参考答案采分点
1为什么保存销售订单不等于出库？订单只是承诺；出库（库存减少）发生在交货的发货过账，移动类型 601，此时才产生物料凭证。答出「发货过账 + 601 + 物料凭证」得满分。
2哪一步产生会计凭证？借贷是什么？发票下达（VF02）时生成：借 客户应收（含税），贷 销售收入（净价值）+ 销项税。借贷方向错一个扣一半。
3价格是怎么进到订单里的？定价过程（由销售范围 + 客户定价过程 + 单据定价过程确定，教材用 RVAA01）按步骤列条件类型；每个条件类型按存取顺序去条件记录里查值（如 PR00 单价、MWST 税）。必须说出「过程 + 存取顺序 + 条件记录」三层。
4销售收入科目怎么定？账码（定价过程中的账码，如 ERL）+ 物料账户分配组 + 客户账户分配组 → 查表得到科目（VKOA/账户确定）。教材里只按物料分为自制产品 M1 与贸易商品 M2 两个科目。答出三个键中的任意两个给一半。
5客户主数据为什么有销售范围层？同一客户在不同公司代码/销售范围可以有不同销售数据（定价过程、运送条件、税分类、伙伴角色），所以除了全公司共用的一般数据，还要有销售范围级数据。提到「不同销售范围可不同」即可。
6四个伙伴角色是什么？售达方（下单）、送达方（收货地）、收票方（开票对象）、付款方（付款与应收）。四个角色必须全对。
7订单保存时提示库存不足，能不能继续？默认可以继续保存（可用性检查不阻止保存，只给确认日期）；后续要发货必须补库存，教材用 MB1C + 移动类型 501（无订单收货）录入期初库存。答出「可以保存」+「501 补库存」。
8为什么开票之前必须有交货？交货相关开票以交货的已发货数量与金额为基础；没有交货（或未发货过账）就没有可开票的数据，VF01 的可开票清单为空。答出「发票参照交货」。
9销售范围由什么组成？销售组织 + 分销渠道 + 产品组；教材场景 1×2×2 = 4 个。三个键全对。
10客户说「我的货到哪了」，你查什么？单据流（VA03/VL03N 的环境 → 显示单据流）看下游单据；看交货状态（未交货/部分/完全）与发货状态（是否已 PGI）；用 VL06O 看待发货。答出单据流或状态字段之一。
11销售分析报表没有数据，先查什么？① 抬头/项目更新组是否激活（任务 31/32）；② 客户与物料主数据的统计组是否维护；③ 数据是否在配置之后产生。答出前两条给满分。
12改了主数据，为什么老单据没变？单据保存时数据是快照；主数据变更只影响新建单据（或需手改单据/重新定价），这保证了历史单据的可追溯性。答出「快照」意思即可。

5. 课堂常见提问（现场速答）

学员会问怎么答
「订单类型 OR 能不能改？」OR 是标准订单类型；可以复制出 Z 类型再改，不建议直接改标准对象。改的是 IMG 里的销售凭证类型。
「为什么我的价格是 0？」先查条件记录（VK13）里有没有该销售范围 + 物料的 PR00；再查定价过程确定的三键。
「客户编号为什么有两个？」售达方与送达方可以是不同客户编号，通过伙伴角色关联；也可用同一客户的不同编号。
「一定要建报价吗？」不必须：可以直接 VA01 建订单。报价用于有议价过程的场景，好处是可追溯与跟进。
「能不能跳过交货直接开票？」标准流程不行；有订单相关开票等变体，但课程场景是交货相关开票。
「发货过账错了怎么改？」按顺序冲销：发票（VF11）→ 发货过账（VL09）→ 再重做。不要直接删单据。
