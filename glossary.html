3. 单据类型 / 类别代码

代码含义用在哪
IN询价 InquiryVA11
QT报价 QuotationVA21
OR标准销售订单VA01（教材场景）
LF外向交货VL01N
F2发票（教材场景）VF01
G2贷项凭证（冲销/退货常用）VF01
TAN标准项目类别订单行
AG / WE / RE / RG售达方 / 送达方 / 收票方 / 付款方伙伴角色
601发货出库移动类型发货过账
代码随系统而异上面的代码是「常见值」，不是唯一值：OR / LF / F2 / TAN 都是可配置的，很多公司会复制出自己的 Z 类型。学习时记住「代码代表什么角色」，用 F4 看自己系统的取值。

4. 常用表（看数据用）

表内容用 SE16N / SE16 查看
VBAK / VBAP销售订单抬头 / 项目按订单号
VBEP计划行（需求传递、确认数量）按订单号
LIKP / LIPS交货抬头 / 项目按交货号
VBRK / VBRP发票抬头 / 项目按发票号
KONV单据条件（这张单实际用的价格）按单据号
KONH / KONP条件记录抬头 / 金额按条件类型
KNVV客户销售范围数据按客户 + 销售范围
MVKE物料销售视图（销售组织/渠道级）按物料 + 销售组织
TVKO / TVTW / TSPA销售组织 / 分销渠道 / 产品组组织数据
TVAP / TVEP项目类别 / 计划行类别定义凭证控制
VBAK 与 VBFAVBFA = 单据流（上下游关系）按单据号查流向
关于表名表名属于「技术细节」，业务用户不必背；但顾问做排错时非常有用（比如 VBFA 能直接查单据流、KONV 能查这张单实际用的价格）。访问需要相应权限。
